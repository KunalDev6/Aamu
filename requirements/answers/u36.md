# U36 — explaining steps, what Done does, and how the day's size is chosen

Source: direct user message, 15 November 2026 (Europe/Helsinki), in the Claude Code session. The changes were made in that session, not by the Codex agent.

## User message (verbatim)

“the flow of the demo is still weird once i make the goal, it should be clear what a step means too and what happens when a user completes a goal? and how can we demo the ai deciding what step we take each day, is there any backing for this?”

## Changes

1. **“How your mornings work” (`mobile/src/app/how.tsx`).** After the guided demo's goal is approved, this screen replaces the jump back to Home. Three numbered points: the alarm notices snoozes and time to get up; that picks one step (“A step is one small action for today”), Tiny/Small/Full by morning; finishing it lets the next one grow, and not getting to it keeps the next one small. Then the goal's ladder, and “Goals don't run out. When the Full step starts to feel easy, you can make the goal bigger or add another one in Settings.” Buttons: “Ring alarm” (primary) and “Back to Home”.
2. **“How Aamu chose this”** on the guided morning's step card. It shows the actual rule with that morning's numbers: snoozes against the usual and its points, time to get up against the usual and its points, the total and which morning it makes, the size limit for that morning, the carried size, and that today's step is the smaller. It says when the usual is still the starting default (0 snoozes, 8 minutes, until five qualifying mornings) and that these are starting values, not clinically validated. It is recomputed with the same `scoreMorning` / `getCarrySize` / `sizeForMorning` code; nothing is model output.
3. **What Done does.** The demo card and the real Home now say, after Done: “Done. Next time this goal comes up, the step can grow to {next size}.” (for Full: “That was the full step. Next time this goal comes up, it can be Full again.”). After “Not today” Home says “Not today. The next step stays small.”
4. **Home during the guided demo:** “Ring alarm” is the primary button and the alarm-permission notice is hidden, so the presenter's next action is clear.

## Decision record — who decides the daily step

The daily step size is chosen by fixed, published rules from the morning's sensing (snoozes and time to get up against the person's own baseline), not by a language model. The AI's roles are: Gemini Decision classifies the goal and judges step durations; Gemma writes the steps; Thompson sampling learns which moment to show. This was not changed. Moving the daily choice to a model would send each morning's data to the provider and make the choice unexplainable; any such change needs the user's decision.
