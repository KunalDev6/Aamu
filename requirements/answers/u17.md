## Early hold

minutesBeforeAlarm = floor((scheduledAlarmTime − holdCompletedAt) in minutes), a non-negative integer set only on early holds and null otherwise; nothing further was specified. The “I’m already up” window opens at the later of (scheduled alarm − 180 minutes) and local midnight of the alarm’s calendar day, and closes when the alarm fires. It never appears on the previous calendar day. localDate for an early hold is the alarm’s calendar date. Tests: 07:15 alarm opens the control at 04:15; 02:00 alarm opens it at 00:00, not 23:00 the day before; early hold at 00:30 for a 02:00 alarm stores minutesBeforeAlarm: 90 and the alarm’s localDate.

## Clinic wording

Clinic wording: stopped with upAt set → “alarm stopped; getting up confirmed later”; stopped without upAt → “alarm stopped but getting up not confirmed”. Count the two separately in the reason; both keep value 2 and both count in the hard/stopped rules.

## Previously synced goal becoming localOnly

When a server-stored goal becomes localOnly, the next PUT /goals removes its title and step texts from the server, and the backend sets stepText to null on all existing morning records with that goalId, keeping the opaque ID, sizes and outcomes.

## Message learning

Message learning: timesPlayed increments once per message per local day when audible playback reaches 3 s, or the end if shorter. Show today’s step as soon as the message starts. Replays the same day add nothing. Only the morning’s selected message can earn credit: increment timesFollowedByDoneStep when stepDone becomes true that local day, and decrement if “Done” is undone. A rested message earns no play and no credit; a message paused after the threshold still counts. Playback from Settings never counts.
